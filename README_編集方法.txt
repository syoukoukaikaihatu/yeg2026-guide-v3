YEG祭2026 管理画面付き・完成版

■ 管理画面を開く
公開URLの末尾に ?edit=1 を付けます。
例：https://yeg2026-guide-v3.vercel.app/?edit=1

■ 出店者情報の編集
1. 管理画面の「出店者情報を編集」を押す
2. 番号を選び、店舗名・提供品目・アルコール・画像名を修正
3. 「画面に反映」を押す
4. 「shops.jsを保存」を押す
5. 保存した shops.js をGitHubの同名ファイルへ上書き

■ 写真の変更
1. 「新しい写真」から画像を選ぶ
2. 「画面に反映」を押す
3. 「写真を16:9で保存」を押す
4. 保存した画像をGitHubへ上書き

※静的サイトのため、ブラウザからGitHubへ直接保存はできません。ダウンロードしたファイルをGitHubへ上書きする方式です。
※既存写真はサイト上で16:9枠に統一表示されます。元画像ファイル自体は変更していません。

■ 地図位置の編集
従来どおり番号・縁日・TIMETABLEを調整後、「編集済みHTMLを保存」でindex.htmlを書き出し、GitHubへ上書きしてください。
